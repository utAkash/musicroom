04 Before you ask

Small print.
Big clarity.

No surprises hiding behind a settings menu. Here's everything you need to know.

Still curious? The room demo is the fastest way to see it in action.

Do I need a Spotify or YouTube account?

No account, no login, no email. Pick a nickname and you're in. MusicRoom plays public YouTube videos through YouTube's official embedded player, so no account is needed on our side.

What if search says the quota is exhausted?

YouTube limits API searches each day. When that happens, MusicRoom keeps working: paste any YouTube link directly into the room and it joins the queue as usual. Shared playback, chat, and voting are unaffected.

Will we actually be in sync?

Yes. The host broadcasts the current playhead every three seconds. Each listener checks their local player once a second and quietly seeks back if they drift by more than three seconds. You won't need to coordinate countdowns.

Does it work on my phone?

MusicRoom is a responsive web app, so it works in any modern mobile browser. Phones sometimes block unmuted autoplay; if that happens, a single “tap to join the audio” button puts you in at the exact room position.

Is it really free?

Yes. It's built as a lightweight static app, so it can run on free Firebase, YouTube API, GitHub, and Vercel tiers. There are no ads, no subscriptions, and no paid rooms. Ever.
